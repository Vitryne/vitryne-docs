## Sobre o Projeto

O **Vitryne** é uma plataforma digital que conecta consumidores a lojas de moda locais — boutiques, confecções e lojas de bairro — por meio de catálogo digital, busca por proximidade geográfica, pagamento integrado e delivery com modelo de prova e devolução em casa.

Este repositório centraliza todos os artefatos produzidos ao longo do ciclo de vida do projeto, seguindo as etapas da Engenharia de Software: levantamento de requisitos, modelagem, implementação, testes e deploy.
